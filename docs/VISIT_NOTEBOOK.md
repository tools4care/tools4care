# Visit notebook

The visit notebook replaces temporary notes taken outside Tools4Care while
collecting requests inside a barbershop.

## Field workflow

1. Open **Daily Route**.
2. Press **Notebook** for a general notebook, or the notebook icon on a
   specific route stop.
3. Select an existing barber/customer or write a name manually.
4. Type the requested product. Catalog products appear as suggestions, but a
   free-text request is also accepted.
5. Add quantity and an optional short detail.
6. Repeat for every barber in the shop.

## VAN workflow

1. Open the same barbershop and date.
2. Check each item while loading it from the VAN.
3. Press **Start sale** for a barber linked to a customer account.
4. Tools4Care opens Sales with that customer selected and copies their
   unsold requests into the sale notes.
5. Mark individual lines sold as they are delivered.
6. Mark the notebook **Complete visit** when finished.

The notebook does not silently add products to a cart. This is deliberate:
inventory availability, exact variants and final quantities are confirmed in
Sales before stock is changed.
